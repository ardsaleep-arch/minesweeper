# 💣 Minesweeper

เกม Minesweeper บนเว็บ เขียนด้วย HTML, CSS และ JavaScript ล้วน ในไฟล์เดียว (`index.html`)

## วิธีเล่น

- **คอมพิวเตอร์:** คลิกซ้ายเพื่อเปิดช่อง คลิกขวาเพื่อปักธง
- **iPad / โทรศัพท์:** แตะเพื่อเปิดช่อง กดค้างเพื่อปักธง หรือเปิด "🚩 โหมดปักธง" แล้วแตะเพื่อปักธง
- ขนาดกระดานปรับให้พอดีกับหน้าจอโดยอัตโนมัติ (รองรับการหมุนจอ)
- คลิกที่ตัวเลขที่ปักธงรอบข้างครบแล้ว เพื่อเปิดช่องรอบ ๆ ทั้งหมด

## ระดับความยาก

| ระดับ | ขนาด | ระเบิด |
|---|---|---|
| เริ่มต้น | 9 × 9 | 10 |
| ปานกลาง | 16 × 16 | 40 |
| เชี่ยวชาญ | 16 × 30 | 99 |

## เริ่มใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
